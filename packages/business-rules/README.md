# Business Rules

Shared business-rule functions for reservations, commissions, returns, delivery fees, and state transitions.

Foundation constants currently include:

- 15-minute reservation lock after payment initiation.
- Maximum 5 active reservations per phone.
- Free pickup and 50 KSh Kikuyu local delivery.
- 7-day affiliate attribution window.
- 24-hour commission confirmation delay after delivery.
- 24-hour return request window.
