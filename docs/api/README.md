# API Documentation

This directory will hold OpenAPI contracts and API design notes.

Initial API groups:

- Foundation: auth, employees, roles, permissions, audit logs.
- Product: barcode, images, AI extraction, review, publishing.
- Inventory: locations, check-in, movement, reservations, picking state.
- Transaction: cart snapshot, order, order items, cancellation.
- Payment: M-Pesa initiation, callback, reconciliation, refund.
- Fulfillment: picking, packing, pickup, delivery, return.
- Affiliate: referral links, attribution, commission, settlement.
- Data Operations: events, dashboards, exports.
