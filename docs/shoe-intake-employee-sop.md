# Shoe intake · 鞋类录入

Updated 2026-09-06. One matching pair is one product, one barcode and one inventory unit.
一双配对鞋 = 一个商品 = 一个条码 = 库存一双。

## 1. Prepare and photograph ten pairs · 先拍十双

1. Keep ten pairs in positions 1–10. Keep the left and right shoe together and confirm the same model and size. Do not combine mismatched shoes to make a saleable pair.
   十双按 1–10 编号摆放，左右鞋保持配对；不同款或不同尺码不能拼成一双上架。
2. Photograph all ten pairs before sitting down to upload. Use a plain background, enough light and the same numbering order. Shoes do not need the garment measurement board.
   集中拍完再坐下上传；背景干净、光线清楚，顺序不变，鞋子不用服装测量板。
3. Each pair needs four original views: **整双主图** (both shoes together), **侧面图** (show both shoes' sides), **鞋底图** (both soles), **尺码标签图** (readable markings to compare both sizes). Add **瑕疵图** for visible damage. The existing upload slots FRONT/BACK/DETAIL/LABEL carry these four shoe views.
   每双必须有整双、侧面、鞋底、尺码标签四类图；需要时用清晰合照展示左右鞋标签。瑕疵另补特写。
4. If a label is missing or unreadable, set the pair aside for the supervisor to verify. Do not invent a size, convert from outsole length, or mark a mismatched pair as confirmed.
   无标、模糊或左右不一致的鞋先留待核实，不猜鞋码、不用外底长度换算鞋码。

## 2. Upload and confirm · 上传与校准

1. Open **商品中心 > 新建批次**, choose **鞋类 · 一双一个商品** and create a batch of ten. Upload photos under matching item numbers. The bulk file selector assigns only the pair overview photos in order; add the other views to each matching pair.
   新建鞋类批次，每批十双；批量选择仅分配整双主图，其余照片按对应编号补入。
2. Start batch AI processing. Shoe recognition uses the original photographs. The system does not run the clothing cutout or clothing measurement process on shoes.
   启动 AI 识别，鞋类使用原图，不走服装抠图和测量流程。
3. Confirm the title, category/audience, shoe type, color, material when known, price and condition. Enter the original label and the size system: EU, UK, US Men, US Women, US Kids, CM, or another clearly identified system. Keep any conversions printed by the manufacturer as evidence; the system does not calculate conversions.
   核对鞋款、颜色、价格、成色，填写原标鞋码和码制；系统只整理显示，不推算换码。
4. Compare the actual pair with the photos. Check both soles, uppers, interiors, heels and fastenings for wear, cracks, loose glue or missing parts. Write an accurate customer-visible condition note, and record defects separately. Then tick the same-model/same-size pair confirmation yourself.
   检查鞋底、鞋面、内里、鞋跟及鞋带/扣件，记录磨损、开胶等鞋况和瑕疵；员工亲自确认同款同码配对。
5. Removable insole length is optional. Only enter a real manual measurement in centimetres; do not copy an AI estimate or measure the outsole instead. The length does not imply a recommended shoe size.
   鞋垫长度可选，只填人工实测；不使用 AI 猜测，不把外底长度当鞋垫长度。

## 3. Review images, label and store · 审图、贴码、归位

1. Save all ten pairs. The system prepares shoe sales details and AI display images, generates the matching barcodes and assigns shelf locations.
2. Check each AI display image against the originals and actual pair. It must retain both shoes, their model, shape, material, logos, laces and real wear. Reject images that hide damage, replace a shoe or make the pair look newer. AI suggestions do not establish authenticity or physical condition.
3. Print the existing barcode label for each pair. Match item number, image, shoe size and shelf code. Attach one label to the pair's bag or tie; keep the shoes together. Do not create one product for each foot.
4. Place pairs by the grouped shelf list. Confirm printed labels only after checking the paper, and confirm the batch stored/published only after all pairs are correctly labelled, placed and their AI images checked.
5. Check the result and storefront: ten products, original shoe sizes, shoe condition, images and price. Resolve any reported item in the same batch. Reprint a damaged label with the same barcode; never duplicate the product.

Use the existing barcode and shelf steps in [Product Factory employee SOP](product-factory-employee-sop.md). A matching pair, clear size, all four original views and human condition notes are required before shoe approval/publication. An AI display image still requires human confirmation before publication.
